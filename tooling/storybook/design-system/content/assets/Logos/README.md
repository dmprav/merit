# Logos

`merit-mark.svg` is Merit's mark: two overlapping rounded lozenges, drawn on a 100 × 100 box. The source renders it in `currentColor` and colours it `action` (#455779); this file bakes that ink in, because an `<img>` cannot inherit colour. Set it at 1.2em beside the wordmark.

The wordmark has no file: it is the word **merit**, lowercase, in the system sans at weight 700 with −0.05em tracking and 1.2 line height, 0.3em after the mark. Never redraw the mark or set the word in another case.
