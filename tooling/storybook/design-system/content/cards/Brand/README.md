# Brand

Merit's mark and lowercase "merit" wordmark, used at the start of the application shell.

- Render it inside a link: the containing link owns navigation and its accessible name (for example `aria-label="Merit home"`).
- The mark is a decorative SVG (`aria-hidden`) drawn in the `action` colour via `currentColor`; the wordmark inherits the surrounding text colour.
- It takes no props. Do not resize, recolour or restyle it; the shell places it.
- Use it once per page, in the application navigation.

Exports: `Brand`.
