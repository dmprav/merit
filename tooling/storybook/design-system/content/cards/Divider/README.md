# Divider

A decorative rule between blocks of content, such as above a page's secondary actions.

- Layout spaces it from its neighbours: place it inside a `Stack` and let the gap set the space around it.
- Use `Stack`'s `divided` option, not repeated Dividers, for rules between list entries.
- `tone="default"` draws a `border` rule. Reserve `tone="emphasis"` (an `action`-coloured rule) for the one rule that marks the current or recorded side of a comparison.
- It is decorative; headings and landmarks carry the structure.

Exports: `Divider`.
