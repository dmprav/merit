# Security policy

## Supported scope

Security fixes target the current `main` branch and any deployment operated by
the maintainer. Older commits, forks, and third-party deployments are not
maintained. Merit is a portfolio and learning prototype, not a live
grant-management service; see the [project context](docs/foundations/strategy.md#current-purpose-and-working-context).

Report issues affecting Merit's application, authorization, workspace isolation,
or handling of credentials and data, including vulnerabilities in dependencies
that affect Merit.

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting form](https://github.com/dmprav/merit/security/advisories/new)
to report a security issue to the maintainer. The
[repository setup guide](docs/guides/development.md#security-reports-and-alerts)
describes reporting and alert settings.

Do not post vulnerability details in public issues or pull requests. Include
the affected commit or deployment, steps to
reproduce the issue, and its potential impact. Remove credentials and personal
data from examples.

Reports are reviewed as maintainer capacity permits. No response or remediation
time is guaranteed.
