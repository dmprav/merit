# Verification record

## Behavioral decisions

- Managers could attach five optional PDFs of up to 25 MB each. Manual intake fields governed readiness. The public demo offered three bundled files.
- Recording changed files advanced the material version. Reviewers accessed the files from their assigned version and MCP listed file metadata for a requested version.

- PostgreSQL integration tests passed for creation, revision, historical file access, reviewer assignment and revocation, and version-specific MCP listings. Removing the final PDF, reloading the draft, and publishing kept the earlier version readable.
- The upload HTTP tests passed, including rejection of malformed content before storage, size limits, same-origin writes, and sample-only demo uploads. Private storage integration and the package dependency audit passed.
- The application build and typecheck, repository code and architecture checks, complexity, React Compiler, CSS, documentation, and secret checks passed. The Applications domain suite passed 127 tests, the Applications web suite passed 71, and Grantmaking passed 211.
- All eight desktop and narrow-screen Storybook checks passed for the applicant submission form and assigned review switcher, including accessibility, focus, overflow, and runtime errors.
- Browser tests passed for upload at creation, reading the stored bytes beside an unfinished form, and sample selection. The intake and reader flow passed in Chromium, Firefox, and WebKit. In Chromium a four-page PDF retained page 4 after switching to criteria and back.
- Independent review caught last-file removal after a draft reload and rejection of unreadable files. Both regressions passed after correction.
- CI identified the dynamically loaded PDF worker as unreachable. The uncached code-health check reproduced the finding and passed after the worker was registered as a runtime entry.
- Automated review identified a disappearing published PDF when editing metadata and lost keyboard focus after removing a file. Both focused tests failed before the fixes. All 25 application workspace tests and four PDF field tests passed afterward, including selection and retry outcomes.
