# Verification record

## Behavioral decisions

- The worker uses its supplied environment for the database and public origin. Its assistant, reviewer messages, and organization invitations use the same origin.
- The product keeps its public workspace statuses. Forbidden resources stay hidden and activity retains its own invalid-input response.
- Each capability can use approved imports from earlier groups. Reviews, Recommendations, and Decisions remain independent peers. Organizations keeps its transaction rollback behavior.
- TypeScript tracks imported workspace sources in a per-package incremental cache. Vite+ still caches the application bundle separately.
