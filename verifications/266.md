# Verification record

## Behavioral decisions

- Captures desktop-only Storybook screenshots (omits mobile screenshots) via `ui:verify --viewport desktop` to keep PR visuals focused and fast.
- Caps screenshots at 8 stories per PR using round-robin selection across directly changed `*.stories.tsx` files and sibling story files of changed UI/CSS modules, reporting any omitted count.
- Publishes captured PNGs to a single squashed orphan commit on `ci/pr-screenshots` using commit-SHA `raw.githubusercontent.com` URLs (preventing stale CDN caching and git history bloat) and deletes `pr-<number>/` (or the whole branch when empty) on PR close.
- Uses an ephemeral `GIT_ASKPASS` helper for git push/fetch inside the Playwright container instead of embedding tokens in remote URLs.
