Git removes its own partial checkout when interrupted by a signal, `worktree:clean <slug>` still removes an unrecorded checkout at the default path, and a complete custom `--dir` checkout is an ordinary Git worktree that `git worktree remove` clears. Recording an ownerless intent would need a separate ownership proof for clean to use before it removes anything, which is too much for that window.
