# Verification record

## Behavioral decisions

- One heading scale, every level at `--weight-heading`:
  - page: `--text-page`;
  - section (level 2): `--text-section`, now 17px;
  - subsection (level 3): new `--text-subsection` (15px);
  - levels 4–5: `--text-body`.
- Inside work-pane, dialog and side-panel bodies, levels 3–5 render at `--text-body` so they never outrank the frame title, matching DialogSection. Reference panes (`data-reference-body`) keep the full scale, so a question is never smaller than its answer.
- A level-2 heading in a reference pane's reading content keeps the section size: the pane bar is a document switcher, not a content title. The duplicate heading under the switcher is left to the showcase PR.
- Quiet pane headings use `--foreground`, `--text-detail` and `--weight-heading`, so none is lighter than the content under it. That includes OutcomeSummary titles in the committee decision pane.
- New `--space-section` (28px) separates consecutive sections in PanelSections, page compositions, DialogSection, and the feature screens that hand-set it. `Stack gap="section"` exposes it publicly.
- PageHeader lays out a full-width kicker row with title and actions beside each other. The actions box is one title line tall, so actions centre on the title's first line even when the title wraps. Below 600px they wrap one `--space-4` under the context.
- DescriptionList:
  - stacked values have no control-height floor, so labels sit beside their own values;
  - rows use a `minmax(7.5rem, 8.5rem)` label column;
  - figure values share an end edge.
- PropertyButton keeps `--control-height-small`, and read-only rows in an editable properties list share that height. PropertiesLayout reaches into its DescriptionList rows for this.
- `intake-form.tsx` no longer skips from level 3 to level 5.
