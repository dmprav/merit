# Verification record

## Behavioral decisions

- Focus returns to the same controls as before: Add on review work, the section's edit trigger on intake, and the section's edit trigger on round preparation. It now moves one frame after React commits the closed editor or picker, rather than one frame after the close was requested.
- A focus request that a re-render cancels before its frame runs is rescheduled, not dropped.
- Intake restores focus only when focus fell to the page as the editor closed. If the person moved focus elsewhere while a save was still finishing, focus stays where they put it, as `docs/guides/ui-verification.md` asks for delayed saves. This uses the same `document.body` check as `application-contact.tsx`.
