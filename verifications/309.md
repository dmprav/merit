# Verification record

## Behavioral decisions

- A story file is affected when it changed or imports a changed module through the Storybook preview's import graph. Type-only imports do not count, because the bundle drops them.
- A change to `.storybook/preview.tsx`, or to a module it imports, affects every story. No story counts as directly affected by such a change.
- Ties at the same import distance go first to story files beside a changed module that stories render, then by path. Changed tests and stories do not raise their neighbors.
- The screenshot job runs for any non-test source under a package's `src/`, a story, or `.storybook/`. `select` exits without screenshots when no story imports a changed module.
