- The audit compared each sampled relative with the same DOM node in both snapshots. Visibility changes counted when the visible side drew a supported cue. Backgrounds and borders needed box area. Outlines and outer shadows with positive spread could paint beyond a zero-size box. Text decorations needed a visible color and a laid-out text run reached by the decoration.
