# Verification record

## Behavioral decisions

- Shared `@merit/ui` CSS, excluding `*.stories.module.css` and `tokens.css`, accepts only:
  - spacing, inset and gap values that are tokens, `calc()`/`min()`/`max()`/`clamp()` of tokens, percentages, `0` or `auto`;
  - radii that are `var(--*-radius)`, `calc(var(--*-radius) - Npx)` for nested corners, `0`, `50%` or `999px`;
  - durations and delays that are `var(--motion-*)`;
  - z-index values that are `var(--z-*)` or `0`–`2`;
  - `svg`/`.icon` sizes that are `var(--icon-size*)`.

  1px hairlines stay allowed. Local custom properties holding spacing, radius or time values follow the same rules.

- The brand wordmark keeps one scoped disable for its em gap, because it scales with the wordmark's own size.
- New tokens:
  - `--space-0-5`, `--space-1-5`, `--space-2-5`, `--space-3-5`;
  - `--space-gutter`, `--space-gutter-wide`;
  - `--icon-size`, `--icon-size-small`;
  - `--badge-radius`;
  - `--motion-spin`, `--motion-sweep`, `--motion-delay`;
  - `--z-sticky`, `--z-drawer-modal`, `--z-modal`, `--z-toast`, `--z-skip-link`.
- Icons are sized by `--icon-size` through `:where(.icon)`, so a control's own class still wins. `IconBase` no longer hardcodes 16px.
- `Count` (`@merit/ui/count`, `tone` neutral or warning) is the one count style for tabs, SectionHeader, Disclosure and request history. It has no outer margin; callers set the gap (`--space-1-5` in flex rows).
- Separators inside popovers use `--border-subtle`; the popover border stays `--border-raised`.
- The `featureStyles` exceptions keep the base stylelint rules and skip only the feature property bans.
