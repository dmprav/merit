# Verification record

## Behavioral decisions

- A detached command's process group counts as stopped only when no member is left. Its leader's exit proves nothing.
- `runCommandAsync` stops the group after every exit, success included, so no descendant outlives the command that started it.
- On Linux, a zombie member does not keep the group alive. It holds no ports or pipes, and in a container whose PID 1 never reaps orphans it would otherwise hold every teardown to the full grace period and report a failed cleanup.
- A group that still has a member after SIGKILL makes the stop reject, so the cleanup stack logs the failure.
