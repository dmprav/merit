# Foundations

The direction, principles, and system design that guide choices across Merit.
Strategy distinguishes enduring commitments from the current working context
and open hypotheses. Domain concepts give those commitments shared meaning;
experience, architecture, and engineering principles explain how to preserve and
build them reliably.
