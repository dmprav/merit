# Grant management domain

Grant management connects funding decisions, delivery, and learning. This guide
follows that work through the perspectives of funders, applicants, recipients,
and people affected by funded work. Merit's focus is set in the
[product strategy](../foundations/strategy.md).

## Explore the domain
