# Own a small, maintainable design system

Accepted 7 November 2026.

Maintain a small design system and reusable component library to control Merit's
look and feel while keeping maintenance effort modest. Build on React Aria
Components for interaction and accessibility
behavior, with Merit owning visual design and composition. This gives the project
control over its presentation while limiting the behavior it must implement and
maintain.

Use shared CSS custom properties and colocated CSS Modules to keep visual
conventions consistent and component styles together.

Owning the library means maintaining its components as product needs evolve. Keep
it focused on recurring needs, with domain-specific compositions in their features.
