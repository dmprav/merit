# Use Cloudflare Workers for hosting

Accepted 7 November 2026.

Use Cloudflare Workers to host Merit. The project is an opportunity to learn a
platform different from the AWS and Kubernetes environment used at work.

Keep operations simple: marketing, product web, and MCP currently share one
deployment and release. Separate deployments should earn their added complexity
through a concrete operational need.

Evaluate Cloudflare through building the application. Reconsider the platform
if its constraints or integration requirements add substantial complexity to
ordinary application work.
