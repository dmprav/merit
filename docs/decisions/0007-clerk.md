# Use Clerk for hosted authentication

Accepted 7 November 2026.

Use Clerk for web sign-in and MCP OAuth. The goal is a hosted authentication
service that works with the application stack at little or no cost.

Clerk establishes identity; Merit owns memberships and business permissions.
Using a hosted service reduces authentication operations while introducing vendor
dependence and potential subscription costs. Reassess the provider if pricing or
integration requirements stop fitting the project.
