# Toggletip

An info icon that explains something brief beside a value. It previews its text
on hover or keyboard focus, like a [tooltip](?path=/docs/components-tooltip--docs),
and pins it open on press or tap so it can be read at leisure. Every info icon in
Merit is a toggletip, so they all behave the same.

<Canvas of={ToggletipStories.Default} />

## Behavior

- Hover opens it after the shared tooltip delay; keyboard focus opens it at once.
- The pointer can move onto the text without it closing.
- Press or tap pins it open. Escape, or a press elsewhere, closes it, including
  while the pointer is over the text.
- The text is a non-modal popover, not a tooltip, so it can be read and selected.

<Canvas of={ToggletipStories.Pinned} />

## Content and tone

Give the button a `label` that names the topic, and keep the content to plain or
short inline text. Anything needed to finish a task belongs visible beside it.
Use `tone="warning"` for a qualification the reader should not miss; the icon
comes from the shared tone icons, so the shape carries the tone as well as the
colour.
